# 峡谷锐评官 🎴

上传英雄联盟战绩截图，随机抽一位「锐评官」来锐评你。

32 位锐评官 × 22 种文体 × 3 种语气，能抽出 2000 多种组合：李白给你写七言绝句，古代皇帝给你下判决书，老中医给你出体检报告，你家的猫给你发小红书……

国服、外服都能用，截图只用于识别，不会保存。

## 功能

- **🎴 抽卡锐评**：先出卡背，再翻牌揭晓，稀有度分 N / R / SR / SSR，SSR 带金光。卡片按文体换排版：诗词是宣纸竖排配印章，判决书盖红章，还有体检报告、新闻联播、小红书笔记、寻人启事等样式，可以一键保存成图片
- **💬 和锐评官对线**：被锐评了不服，可以回嘴，锐评官会用同一个人设接着怼
- **⚔️ 战犯评选**：上传一局结算截图，给我方五人排名，评出 MVP 和战犯，适合发开黑群
- **📖 锐评官图鉴**：收集抽到过的锐评官和文体组合
- **📊 赛后分析报告**：用召唤师名查询（需要 Riot API key）或演示数据时，可以看单局的数据对比和改进建议

## 自己运行（Windows / Mac 都行）

不会写代码也能跑起来，跟着做大约 15 分钟。

### 1. 安装 Node.js

打开 <https://nodejs.org>，下载 **LTS** 版本，一路“下一步”安装。

安装完打开终端检查一下（Windows 按 `Win + R` 输入 `cmd` 回车；Mac 打开“终端”App）：

```bash
node -v
```

显示 `v22.9.0` 或更高的版本号就说明装好了。

### 2. 下载代码

在本页面点右上角绿色的 **Code → Download ZIP**，下载后解压。

会用 Git 的话也可以：

```bash
git clone https://github.com/XinyuZheng1878/LOL-Roast.git
```

### 3. 安装依赖

在终端里进入解压出来的文件夹，然后运行：

```bash
cd 解压出来的文件夹路径
npm install
```

小技巧：在终端里先输入 `cd `（带一个空格），再把文件夹拖进终端窗口，路径会自动填上。

### 4. 申请 AI 的 API key

锐评由阿里云百炼的通义千问生成，需要你自己申请一个 key：

1. 打开 [阿里云百炼控制台](https://bailian.console.aliyun.com)，用阿里云账号登录（没有就注册，需要实名认证）
2. 开通“模型服务”，新用户一般有免费额度
3. 在“API-KEY”页面创建一个 key，复制下来

**这个 key 等于你的钱包，不要发给别人，也不要上传到网上。**

### 5. 填写配置

把文件夹里的 `.env.example` 复制一份，改名为 `.env`：

- Mac：`cp .env.example .env`
- Windows：`copy .env.example .env`

用记事本或任意编辑器打开 `.env`，把 key 填在 `DASHSCOPE_API_KEY=` 后面，保存：

```
DASHSCOPE_API_KEY=sk-你的key
```

### 6. 启动

```bash
npm start
```

看到 `LOL 锐评已启动：http://localhost:3000` 后，用浏览器打开 <http://localhost:3000> 就能玩了。想关掉的话，回到终端按 `Ctrl + C`。

### 花多少钱？

每次锐评调用一次千问，截图识别和战犯评选还会多调用一次视觉模型。按百炼的价格，一次大约几分钱以内，自己玩基本花不了多少，具体以百炼控制台显示的价格为准。建议在百炼控制台设一个消费预警。

### 常见问题

- **`npm` 不是内部或外部命令**：Node.js 没装好，或者装完没重开终端
- **端口被占用**：在 `.env` 里加一行 `PORT=3001`，然后打开 <http://localhost:3001>
- **页面显示“模板锐评（AI 未连接）”**：`.env` 里的 key 没填对，改好后要重新运行 `npm start`
- **识图服务暂时不可用**：可能是账号没开通视觉模型，在百炼控制台的模型广场里看看 `qwen3-vl-plus` 能不能用；也可以在 `.env` 里用 `QWEN_VL_MODEL=` 换成你能用的视觉模型

## 更多配置（可选）

`.env` 里还可以填：

| 配置 | 作用 |
|---|---|
| `QWEN_MODEL` / `QWEN_REPORT_MODEL` / `QWEN_VL_MODEL` | 锐评、赛后报告、截图识别分别用哪个模型 |
| `RIOT_API_KEY` | 在 [Riot 开发者网站](https://developer.riotgames.com) 申请，用来按召唤师名查外服对局（不支持国服） |
| `ANTHROPIC_API_KEY` | 不用千问、改用 Claude 时填 |
| `PER_IP_LIMIT` / `DAILY_AI_LIMIT` | 防刷：每个 IP 每小时次数、全站每天 AI 调用上限 |

## 代码结构

| 文件 | 作用 |
|---|---|
| `server.js` | 网页服务和接口 |
| `personas.js` | 锐评官人格库（人设 × 体裁 × 语气）和稀有度，想加新锐评官改这里 |
| `roast.js` | 生成锐评、和锐评官对线 |
| `blame.js` | 战犯评选：识别结算截图、计算排名、生成点评 |
| `screenshot.js` | 识别战绩截图 |
| `report.js` | 单场赛后报告 |
| `ai.js` | 调用通义千问或 Claude |
| `riot.js` | 通过 Riot API 拉取外服对局 |
| `limits.js` | 防刷 |
| `demo.js` | 演示数据 |
| `public/` | 前端页面：`index.html` 结构、`style.css` 样式和动态背景、`app.js` 交互 |
